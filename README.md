# Em Dia — Sistema de tarefas

O **Em Dia** é uma aplicação web voltada à organização das atividades do dia a dia. A proposta é reunir os compromissos em um lugar simples de consultar, ajudando o usuário a definir prioridades e acompanhar o que ainda precisa fazer.

## Ideia do projeto

O projeto transforma uma lista de tarefas em uma agenda pessoal interativa. Cada usuário possui seu próprio espaço para registrar atividades, acrescentar detalhes e visualizar seu progresso, mantendo suas informações separadas das demais contas.

## Funcionalidades

- Cadastro e login com e-mail e senha.
- Criação, consulta, edição e exclusão de tarefas.
- Título, descrição opcional e prioridade baixa, normal ou alta.
- Marcação de tarefas como concluídas e possibilidade de reabri-las.
- Busca e filtros para tarefas pendentes e concluídas.
- Contadores de atividades e atualização dos dados em tempo real.
- Interface adaptada para computadores e celulares.

## Identidade visual

O Em Dia utiliza tons suaves de verde, ilustrações e uma organização visual simples. A interface destaca a lista de atividades e os indicadores de progresso para facilitar o acompanhamento da rotina.

## Tecnologias utilizadas

- **HTML:** estrutura das páginas e dos formulários.
- **CSS:** aparência e adaptação para diferentes tamanhos de tela.
- **JavaScript:** interações, filtros e gerenciamento das tarefas.
- **Firebase Authentication:** autenticação dos usuários.
- **Cloud Firestore:** armazenamento e sincronização dos dados, com regras de acesso por usuário.

## Objetivo acadêmico

Aplicar os fundamentos do desenvolvimento web integrando o front-end aos serviços do Firebase, com autenticação e operações de criar, ler, atualizar e excluir dados (CRUD).
